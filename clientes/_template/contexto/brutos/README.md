# Materiais brutos

Coloque aqui, antes de rodar a Skill 01:

- `kickoff-transcricao-bruta.docx` — exportação bruta da transcrição da
  reunião de kickoff.
- `formulario-cliente.docx` (ou `.pdf`) — opcional, formulário que o
  prospect preencheu antes do kickoff, se existir.
- `prints-campanhas/` — opcional, prints de tela das plataformas de anúncio,
  usados pela Skill 08 na análise de estrutura de campanha.

Esses arquivos são a entrada bruta. A Skill 01 lê e limpa esse material,
gerando a versão final em `contexto/kickoff-transcricao.md`.
